## What is Obsidian?

Obsidian is a modern stock analysis platform that helps investors make informed decisions using real-time market data, technical analysis, and AI-powered recommendations.

## Features

- 📊 **Real-time stock data** via Finnhub API
- 🎯 **AI recommendation engine** with buy/sell/hold scoring (0-100)
- 📈 **Interactive price charts** with multiple timeframes
- 💰 **Key financial metrics** - P/E ratio, EPS, market cap, beta, profit margins
- ⚠️ **Risk assessment** with volatility analysis
- 🔍 **Smart stock search** with autocomplete
- 📰 **Live market pulse** ticker with major indices

## Tech Stack

**Frontend:** React 
**API:** Finnhub (stock data, company info, historical prices)
